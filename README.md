## 🚀 Featured Projects

### 🏈 [Fantasy Intel — Fantasy Football Analytics & Decision Support](https://github.com/hhavynn/fantasy)
**Next.js · React · TypeScript · FastAPI · Python · DuckDB · nflverse**

A full-stack fantasy football research platform built to go beyond box scores and surface the data behind decisions.

- Built **player research, matchup analysis, waiver intelligence, start/sit tools, trade evaluation and discovery**, and league analytics.
- Developed context-aware forecasting research around **usage, opportunity, injuries, teammates, and defensive matchups**.
- Added model evaluation workflows that compare recorded pregame projections against actual results and ESPN baselines, with explicit coverage and evidence thresholds.
- Designed a responsive dashboard with mobile navigation, searchable player data, and explainable recommendations.

**[Explore repository →](https://github.com/hhavynn/fantasy)**

### 🎬 [NFL Video Studio & Social Trend Engine](https://github.com/hhavynn/fantasy/tree/main/fantasy-intel/studio)
**Python · DuckDB · Kokoro TTS · Pillow · FFmpeg · Local LLMs**

A local-first content pipeline that turns football data and public sports conversations into short-form video concepts and rendered clips.

- Collects public social/news signals, groups related discussions, and scores trend momentum with an **explainable 0–100 ranking**.
- Generates **vertical, data-backed football Shorts** with narration, motion graphics, subtitles, and review artifacts.
- Uses **source-backed claim checks and automated quality gates** to catch unsupported statistics and presentation issues before release.
- Supports optional locally generated long-form scripts; rendering and publishing are separate steps.

**[Video studio →](https://github.com/hhavynn/fantasy/tree/main/fantasy-intel/studio)** · **[Trend engine →](https://github.com/hhavynn/fantasy/tree/main/fantasy-intel/social)**

### 🏛️ [VSA Website — UCSD Student Organization Platform](https://github.com/hhavynn/vsa-website)
**React · TypeScript · Tailwind CSS · Supabase · PostgreSQL · Vercel**

A production website and administration platform supporting **UCSD VSA's 600+ member community**.

- Built public experiences for **events, galleries, House competitions, ACE, historical archives, and points lookups**.
- Developed admin workflows for **content publishing, applications, member records, attendance imports, and analytics**.
- Integrated **Ask VSA**, a Gemini-backed assistant grounded in admin-curated knowledge, with feedback workflows.
- Implemented database access controls using **PostgreSQL row-level security**, plus testing and deployment automation.

**[Repository →](https://github.com/hhavynn/vsa-website)** · **[Live site →](https://vsa-website-psi.vercel.app)**

### 🍵 [Matcha Scout — Personalized Matcha Discovery](https://github.com/hhavynn/matcha-scout)
**Next.js · React · TypeScript · FastAPI · Python · PostgreSQL · Vercel**

A matcha discovery app that maps review text to taste dimensions and produces explainable recommendations.

- Built a **five-dimension preference quiz** and transparent drink-ranking system with match explanations.
- Designed review parsing with an **optional Gemini structured-output mode** and a safe mock-mode default.
- Built cafe/drink/review data models, curation workflows, and San Diego / Orange County browsing.
- Developed a serverless web/API architecture and local Docker-based development workflows.
